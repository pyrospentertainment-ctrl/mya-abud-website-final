PUBLICAR EN GITHUB + VERCEL
1. Descomprime este ZIP.
2. En GitHub crea un repositorio nuevo, por ejemplo: mya-abud-website.
3. Sube el CONTENIDO de la carpeta (index.html y assets), no una carpeta adicional encima.
4. En Vercel: Add New > Project > Import Git Repository.
5. Selecciona el repositorio y pulsa Deploy. No necesitas modificar Framework Preset ni Build Command.

ENLACES INCLUIDOS
- Spotify
- Apple Music
- Instagram
- TikTok
- YouTube
- OnlyFans

Los botones abren los perfiles oficiales en una pestaña nueva. Cuando exista el enlace directo del estreno de MACHITO, puedes reemplazar el enlace general de YouTube en index.html.

DOMINIO COMPRADO EN WIX
Después del despliegue: Vercel > Project > Settings > Domains > Add Domain.
Escribe tu dominio. Vercel te mostrará los registros DNS que debes copiar en Wix > Domains > Manage DNS Records.
No borres registros MX si utilizas correo electrónico con ese dominio.
